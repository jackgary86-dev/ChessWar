# Bug report template and triage process

**Milestone:** QA and bug checks  
**Labels:** qa, process

- Add `.github/ISSUE_TEMPLATE/bug_report.yml`: steps to reproduce, expected vs actual, seed/round, device and browser, screenshot
- Severity labels: `sev:blocker`, `sev:major`, `sev:minor`, `sev:cosmetic`
- Weekly triage: every new bug gets a severity and a milestone
